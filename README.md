# 🤖 AI Career Twin

An AI-powered career guidance platform built with React, FastAPI, JWT Authentication, SQLAlchemy, and Google Gemini AI.

## Features

- User Registration & Login
- JWT Authentication
- Resume Upload (PDF)
- AI Career Analysis
- Resume vs Job Description Matching
- ATS Resume Score
- Responsive Dashboard

## Tech Stack

### Frontend
- React
- Tailwind CSS
- React Router
- Axios

### Backend
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication

### AI
- Google Gemini API

## Project Structure

AI-Career-Twin/
├── backend/
└── frontend/

## Installation

### Backend

cd backend
python -m venv venv
pip install -r requirements.txt
uvicorn app.main:app --reload

### Frontend

cd frontend
npm install
npm run dev
